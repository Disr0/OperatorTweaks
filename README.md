# Operator tweaks

All in one mod to tweak the experience as an operator.

You can suggest new features for the mod using the github issues or by DMing me[`disr0`] on the RoR2 modding discord server.

Currently supports tweaks for:

### Shield
- Shield Transparency. 

The percent of the original shield transparency

- Shield Duration For Max Charge

Seconds until the shield is fully charged up

- Shield exit time

Delay before the shield is sent flying after key release. Set to 0 for no delay
